# Learning

An empty pointer and an empty token differ: the first selects the root, while `/` selects an empty-name object member. Split tokens before once-only tilde decoding; reversing substitution order changes `~01` into the wrong key. JSON escaping and URI percent decoding are separate representation layers.

Membership is not truthiness. A dictionary can contain null, false, zero, empty text or an empty container; those are successful selections. Numeric text is an exact object key but must satisfy ASCII index grammar in an array. Unicode normalization would change the specified object-member comparison.

Bounds apply before work. Lexical depth/numeric gates precede JSON decoding; all document/reference admission precedes lookup or unsupported schema. Repeated root selection can multiply an admitted input into an oversized escaped report, so input caps alone do not bound delivery.

Exact types require identity checks. Python tuple membership can call equality on a custom metaclass even when the intended goal is to reject that type. A demonstrated regression called six equality hooks; replacing membership with `is` checks fixed it. Recursive snapshot copying is safe here only because admission has already restricted types and depth.

The local drafter's incorrect escape label demonstrates why worker output is reviewed against the standard rather than used as an oracle. An initial hard-link sandbox denial was an unavailable check until app-approved rerun, not a pass. Bandit's credential heuristic also misidentified syntax-token literals; retained evidence and narrow explained suppressions distinguish scanner heuristics from verified bugs.
